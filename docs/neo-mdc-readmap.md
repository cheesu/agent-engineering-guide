# neo.mdc 읽기 색인 (Read map)

코딩 규칙의 **정본(SSOT)**은 아래 파일 하나입니다. **줄 번호는 적지 않습니다.** `neo.mdc`가 바뀌어도 이 색인은 **섹션 제목이 바뀔 때만** 고치면 됩니다.

- **정본 경로**(프론트엔드 루트 기준): `.cursor/rules/neo.mdc`

에이전트/사람이 할 일: 아래 표에서 역할에 맞는 **`##` / `###` 제목**을 `neo.mdc`에서 찾아 읽기(Read). 필요하면 해당 절만 부분 읽기.

## 유지보수 규칙 (이 파일을 쓸 사람용)

1. 규칙 문구를 바꿀 때는 **`neo.mdc`만** 고친다.  
2. `neo.mdc`에서 **섹션 제목을 바꿨으면** 이 색인의 해당 문자열만 같이 고친다.  
3. **줄 번호는 어디에도 쓰지 않는다.**  
4. 역할별로 “뭘 더 읽을지”가 바뀌었으면 표만 수정한다.
